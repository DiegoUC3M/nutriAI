Overview
What is NutriAI?

NutriAI is a cross-platform mobile application that generates fully personalized weekly meal plans based on the user's body metrics, nutritional goals, food preferences, and dietary restrictions. It combines science-based macro calculations with intelligent meal composition algorithms to deliver actionable, day-by-day nutrition plans with automatic shopping list generation.

🧬

Science-Based Calculations

Mifflin-St Jeor BMR formula with TDEE computation and goal-based macro distribution for accurate nutrition targets.

🍽️

Smart Meal Generation

Algorithmic meal planner that composes balanced meals respecting allergies, preferences, variety levels, and macro targets.

🛒

Auto Shopping Lists

Automatic ingredient aggregation across all planned days, categorized by food group with quantity estimation.

📱

Cross-Platform

Built with Flutter for seamless deployment across iOS, Android, Web, macOS, Linux, and Windows from a single codebase.

NUTRIAI PORTFOLIO 1
Core Feature
7-Step Intelligent Diet Generator

The heart of NutriAI is a guided multi-step wizard that collects user preferences and body data, then generates a complete personalized meal plan with full macro tracking.

1

Allergies & Intolerances

Select from 10+ allergen types (gluten, lactose, nuts, shellfish, eggs, soy, fish, peanuts, sesame, celery) with granular exception controls for specific foods within each allergen group.

2

Favorite Foods Selection

Browse categorized food database and mark preferred foods. The algorithm prioritizes these when composing meals, ensuring higher user satisfaction.

3

Disliked Foods Exclusion

Mark foods to permanently exclude from generated plans. A separate step ensures no unwanted ingredients appear in the final diet.

4

Macro Configuration

Automatic mode: Input sex, age, weight, height, and activity level — the app calculates BMR, TDEE, and optimal macros for your goal (lose/maintain/gain). Manual mode: Fine-tune protein (50–350g), carbs (50–500g), and fat (20–200g) with real-time calorie estimation.

5

Duration Selection

Choose 1–7 days of meal planning with quick-select buttons and a visual slider. The circular display provides an intuitive interface for day selection.

6

Plan Configuration

Set meals per day (3–6) with intelligent calorie distribution: breakfast (20–30%), lunch (28–40%), snacks (7–10%), dinner (25–30%). Choose variety level: low (repeat favorites), medium (balanced), or high (maximum diversity).

7

Generated Diet Plan

View the complete meal plan with day-by-day navigation. Each day shows a macro summary (calories, protein, carbs, fat) and expandable meal cards with individual food items, portions, and cooking methods.

🔄 Regenerate Anytime

Users can regenerate their entire plan at any point, returning to step 1 to adjust preferences. The plan persists locally via JSON serialization, so users never lose their current diet even after closing the app.

Under the Hood
Algorithms & Data Engine

Macro Calculator Mifflin-St Jeor

Industry-standard metabolic rate estimation adapted with activity multipliers and goal-based adjustments for precise nutritional targeting.

// Basal Metabolic Rate (Mifflin-St Jeor)
BMR = (10 × weight) + (6.25 × height) − (5 × age) ± offset

// Total Daily Energy Expenditure
TDEE = BMR × activityMultiplier   // 1.2 – 1.9

// Goal-Adjusted Calories
Target = TDEE × goalFactor   // lose: 0.80 | maintain: 1.0 | gain: 1.15

// Macro Distribution
Protein = weight × proteinFactor   // 1.8 – 2.2 g/kg
Fat = targetCal × fatPercent / 9   // 25% – 28%
Carbs = (targetCal − proteinCal − fatCal) / 4

Meal Planner Engine Constraint-Based

A multi-constraint meal composition algorithm that generates balanced daily meal plans while respecting user preferences and nutritional targets.

// For each day in the plan:
1. Filter available foods → remove allergens & disliked
2. Partition by category → proteins | carbs | fats | veggies | fruits
3. For each meal slot:
    → Compose meal based on type (breakfast | snack | main | dinner)
    → Scale portions to match calorie target per slot
    → Apply cooking method variety (grill | bake | steam | sauté | roast)
4. Variety enforcement → exclude recently used (configurable depth)
5. Final adjustment → recalibrate last meal if daily deviation > 5%
